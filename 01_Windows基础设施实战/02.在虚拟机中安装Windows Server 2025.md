## 激活Windows Server 2025
打开系统信息，看到为Evaluation版本
“Evaluation”标记，意味着它们是**180天的免费试用版**。到期后系统会限制功能，需要转换为正式授权版本。注意，**Server Core的评估版无法直接转换为正式版**，必须选择桌面体验版本才能进行转换。
![[Pasted image 20261027225604.png]]
打开powershell，参考相关资源，输入如下命令
```
DISM /online /Set-Edition:ServerStandard /ProductKey:TVRH6-WHNXV-R9WG3-9XRFY-MY832 /AcceptEula
```
![[Pasted image 20261027225904.png]]
提示重启，输入“Y”重启
![[Pasted image 20261027230156.png]]
再次登录，可以看到Evaluation字样已经消失
![[Pasted image 20261027230425.png]]

tips：
激活完后建议拍一个快照，出问题可以一键恢复到初始状态
