# 技术沉淀与排障手记 (IT Infrastructure & Troubleshooting Portfolio)

## 📖 项目简介
本项目是个人计算机底层知识与 IT 基础设施运维的实战沉淀库。

在准备秋招的过程中，我意识到“掌握理论”与“能解决企业真实故障”之间存在着巨大的工程化差距。为了打破知识碎片化、避免简历上的项目“假大空”，我建立了这个知识库。**旨在将曾经做过的、以及新拓展的技术点，通过“理论拆解 -> 环境搭建 -> 故障注入 -> 排障复盘”的闭环，重构为符合企业级标准的实战经验。**

## 🚀 核心排障案例直达 (Highlights)
除了正向的配置步骤，本库更关注**“遇到问题该如何思考”**。以下是已沉淀的典型故障排查与复盘记录：

| 故障现象               | 根因分析                             | 涉及技术/工具                        |
| :----------------- | :------------------------------- | :----------------------------- |
| **加域失败，无法联系域控**    | 客户端DNS指向错误，导致无法解析域控 SRV 记录       | `nslookup`, DNS                |
| **nslookup 返回假超时** | 正向A记录勾选了PTR，但反向查找区域未配置           | `nslookup`, PTR记录              |
| **组策略显示已启用但未生效**   | 实验环境系统未激活，底层授权拦截了个性化模块功能         | `gpresult`, Windows Activation |
| **SMB 共享报错拒绝访问**   | 用户未加入对应安全组，且未重新登录刷新 Access Token | NTFS权限, 安全组                    |
| **同网段虚拟机无法互 Ping** | 虚拟机网卡处于桥接与NAT不同模式，产生“假同网段”       | VMware, TCP/IP                 |
