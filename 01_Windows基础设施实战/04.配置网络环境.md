# 配置VMware虚拟网络

| 模式    | 虚拟交换机  | 特点                                         |
| ----- | ------ | ------------------------------------------ |
| 桥接模式  | VMnet0 | 虚拟机直接“桥接”到物理网卡，和你的物理主机**平起平坐**，会占用真实的IP地址。 |
| 仅主机模式 | VMnet1 | 虚拟机**完全无法访问外网**，只能与宿主机通信，形成一个完全隔离的网络。      |
| NAT模式 | VMnet8 | 虚拟机共享主机IP上网，但**外部设备无法直接访问虚拟机**，虚拟机之间可以互通。  |
